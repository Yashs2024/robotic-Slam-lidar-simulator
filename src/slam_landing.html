SLAM bridges physical range sensor physics with probabilistic state estimation and multi-layer spatial maps.

01 // SPATIAL MAPPING
🗺️
Bayesian Occupancy Grid

Evaluates cell occupancy using recursive log-odds updates: $L(m_i | z_{1:t}) = L(m_i | z_{1:t-1}) + L(m_i | z_t) - L_0$. Uses Bresenham line ray voting with fog-of-war revelation.

02 // SENSOR FUSION
📐
EKF 2σ Uncertainty Ellipses

Propagates state covariance $\mathbf{P}_{t|t-1} = \mathbf{F}\mathbf{P}\mathbf{F}^T + \mathbf{Q}$ and corrects on landmark observations via Kalman gain $\mathbf{K}$. Renders live $2\sigma$ error confidence ellipses.

👥
Monte Carlo Localization (MCL)

Maintains 50 to 500 hypotheses across the state space. Weights particles against LiDAR range likelihoods and executes low-variance resampling to resolve kidnapped robot scenarios.

MOBILE ROBOT KINEMATICS

3 SELECTABLE DRIVE PLATFORMS

Switch between three distinct vehicle drive kinematics models, each with dedicated odometry equations and motion matrices.

01 // TANK DRIVE UNICYCLE MODEL
Differential Drive

Two independent drive wheels with passive castor. Capable of zero-radius in-place turns ($v_L = -v_R$). Non-holonomic velocity constraints.

Kinematics$\dot{x} = v \cos\theta, \dot{y} = v \sin\theta$
In-Place RotationYes (Zero radius)
ConstraintNon-holonomic
02 // CAR-LIKE BICYCLE MODEL
Ackermann Steering

Automotive front-wheel steering geometry. Enforces non-zero minimum turning radius $R = L / \tan\delta$, modeling autonomous road vehicles.

Kinematics$\dot{\theta} = \frac{v}{L} \tan\delta$
In-Place RotationNo ($R_{min} > 0$)
ConstraintSteering angle bound
03 // OMNI-WHEEL 3-DOF PLANAR
Holonomic Omni Drive

Equipped with mecanum/omni rollers. Capable of arbitrary instantaneous translation in any direction $(\dot{x}, \dot{y})$ independent of heading $\theta$.

KinematicsFull 3-DOF planar motion
In-Place RotationYes + Crab walk
ConstraintUnconstrained holonomic

// FREQUENTLY ASKED QUESTIONS //
What are the WebGL requirements for the simulators? ▼
RoboAI Suite requires a modern browser with WebGL 2.0 support. Hardware acceleration must be enabled in your browser settings to ensure 60fps performance during 3D point cloud rendering and 6-DOF kinematics.
How does LiDAR raycasting operate client-side? ▼
The SLAM simulator uses a highly optimized 2D line-line intersection algorithm. It casts 360 rays from the robot's center against all wall line segments in the environment grid. Gaussian noise is injected into the distance readings to simulate real-world sensor inaccuracies.
How does NEXUS handle kinematics singularity? ▼
The inverse kinematics (IK) solver uses Damped Least Squares (DLS) with Levenberg-Marquardt damping. When the Jacobian determinant approaches zero (Yoshikawa manipulability index drops), the damping factor prevents joint velocities from tending to infinity, ensuring stable trajectories near singularity zones.
What is Space-Time A* in HIVE Logistics? ▼
Space-Time A* is a 4D pathfinding algorithm (x, y, rotation, time) used in HIVE. It manages a global reservation table so autonomous mobile robots (AMRs) can plan collision-free paths by factoring in the projected future positions of all other active units in the swarm.
